# Approach Records

Approach records sit between strategy and implementation:

- they explain a recurring geometry problem;
- summarize the alternatives actually tested;
- identify what evidence supports the current direction;
- state what remains unapproved;
- define the next bounded experiment.

An approach record does not promote a Blender object. Promotion still requires
the gates in [validation.md](../validation.md).
